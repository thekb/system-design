# Prompt

## Design a system similar to Netflix, which supports the following features:

* Video Search: Users can search for videos using keywords.
* Video Streaming: Users can stream selected videos online.
* Video Upload: Users can upload their own videos to the platform.

Please describe the overall system architecture,
including your choices and justifications for databases, caching systems, video storage solutions, media streaming servers, and search engines. 

Provide detailed designs for a few core services, including user service, video service, search service, and streaming service.
