# Problem

Design a system that allows users to 
favorite/unfavorite items, 
check their favorite status, 
view favorite counts, 
and see their list of favorited items. 

The system should handle high read traffic (1M QPS for status checks and counts)
and significant write traffic (100k QPS for fav/unfav operations) 
while maintaining data consistency.
